## 1. 系统总体结构

PLC 主程序 `Main` 每个扫描周期依次调用以下核心功能块：

1. `0- IO Configure`
2. `A1-阀带反馈`
3. `A2-阀带阀导`
4. `A3-电机控制`
5. `A4-脉冲控制`
6. `A6-模拟量输入`
7. `A5-模拟量输出`
8. `A7-温度控制`
9. `B1--ALARM`
10. `B2--局部连锁`
11. `B3-全局连锁`
12. `B4-清洗连锁`
13. `C1-开式自动`
14. `C2-闭式自动`
15. `C3-室内CIP清洗`
16. `C4-室外CIP清洗`
17. `D1-室内CIP通讯`
18. `D2-室外CIP通讯`

从结构上看，这套程序分成 6 层：

1. 物理 I/O 与内部符号映射层
2. 阀门、电机、模拟量、温控等基础功能层
3. 报警与联锁层
4. 开式自动与闭式自动生产层
5. 室内/室外 CIP 清洗层
6. HMI 画面、历史、日志与 VB 辅助层

## 3. 开机前通用检查

任何模式启动前，都建议按照以下顺序检查：

1. 确认急停回路已复位，`IJT急停` 无动作，现场急停按钮均释放。
2. 确认送风机、引风机、离心雾化器、进料泵、电加热、输送风机、输送加热等主设备已具备上电条件。
3. 确认关键公用工程正常：
   冷却水、冷冻水、进风冷却水、空压、氮气、纯水、碱液、溶剂、排液回收等系统具备使用条件。
4. 确认关键反馈信号正常：
   隔断阀开关反馈、补氮阀反馈、进氮阀反馈、清洗球阀反馈、伸缩气缸升降反馈、爆破片反馈等。
5. 确认温度、压力、压差、液位、氧含量等关键仪表无故障。
6. 确认当前工作方式：
   开式生产、闭式生产、室内 CIP、室外 CIP 不能混用；切换前应先停机并做模式确认。
7. 确认参数页已按工艺要求设定完成。
8. 首次启机或切换工艺时，先用手动模式验证关键阀门和电机动作方向，再转自动。

## 4. 开式手动操作流程

对应页面：`C1_开式手动界面`

开式手动适合用于单机试车、点动、检修确认和开式生产前的准备。

### 4.1 建议启动步骤

1. 进入 `C1_开式手动界面`，确认开式相关隔断阀处于正确初始位。
2. 打开开式通路对应阀门，关闭闭式通路对应阀门。
   一般应重点确认 `QKS开式排风隔断阀`、`QKS开式进风隔断阀` 与 `QBS闭式排风隔断阀`、`QBS闭式进风隔断阀` 的状态。
3. 启动送风机、引风机，观察反馈和运行频率是否正常。
   重点信号包括 `QSF送风机`、`QYF引风机`、`ISF送风机`、`IYF引风机`。
4. 按需要投入电加热、输送风机、输送加热。
5. 启动离心雾化器，观察转速、油压和风扇状态是否正常。
6. 待温度、风量、塔压趋于稳定后，再投入进料泵。
7. 根据工艺需要投入脉冲、振打和出料装置。
8. 在手动模式下逐一确认以下对象的动作是否正确：
   风机、雾化器、进料泵、冷却水阀、排液阀、出料阀、清洗相关阀门、气缸升降等。

### 4.2 手动运行关注点

1. 观察 `PV_JF进风温度`、`PV_CF出风温度`、`PV_TN塔内压力`、`PV_JL进料压力`、`PV_BD布袋压差变送器`。
2. 手动调整时，尽量一次只改变一个对象，避免联动误判。
3. 若手动点动阀门时开关反馈不变化，应优先确认阀岛、气源、接线和到位开关。
4. 若风机、雾化器或进料泵启动后反馈异常，应立即停下并查驱动器/接触器/热继电器/变频器状态。

### 4.3 开式手动停机步骤

1. 先停进料泵。
2. 维持风机和必要的雾化/排风一段时间，完成塔内带料和余热排空。
3. 再停加热。
4. 继续保持风机短时运行后停送风、停引风。
5. 关闭开式通路阀门，恢复安全初始状态。

## 5. 开式自动操作流程

主页面：`C2_开式自动界面`

参数页面：`C3_开式自动参数A`、`C4_开式自动参数B`

### 5.1 自动前参数确认

开式自动前建议重点确认以下设定：

1. 进风温度设定、出风温度设定及高报/高高报。
2. 送风、引风、雾化、进料相关频率或自动设定值。
3. 进料流量设定、进料压力报警值、停机阈值。
4. 布袋压差报警值、自动反吹触发值和反吹时间。
5. 各出料阀开关周期、振打/脉冲时间。

说明：当前工程中可见的典型设定量包括：
`SV_JF进风温度设定`、`SV_CF出风温度设定`、`SV_YF引风频率设定`、`SV_JL进料泵频率设定`、`SV_BD布袋压差自动反吹`、`SV_BD布袋反吹时间`、`SV_BD布袋振打时间` 等。

### 5.2 自动启动建议顺序

1. 进入 `C2_开式自动界面`，确认系统处于停止且无未复位故障状态。
2. 确认开式隔断阀动作正确，闭式隔断阀未误开。
3. 按“自动启动”后，系统应按联锁允许条件逐步完成：
   风机建立风量和塔内流场，温控开始建立，雾化投入，进料投入，脉冲/出料按设定进入自动节拍。
4. 运行中应持续观察出风温度、塔压、布袋压差、进料压力、氧含量趋势是否异常。
5. 若出现温度、压差、阀反馈、风机故障等异常，系统可能会触发联锁停机或退回保护状态。

### 5.3 自动停机建议顺序

1. 正常停机时先执行自动停机。
2. 自动停机后应先停进料，再进行必要的吹扫与余热带走。
3. 加热退出后保留送/引风短时运行。
4. 确认塔内压力、温度、压差回落到允许范围，再完全停风机并关闭阀门。

## 6. 闭式手动操作流程

对应页面：`B1_闭式手动界面`

闭式手动模式适合用于闭式工艺切换前的惰化确认、保压动作确认、闭式阀门与风机试车。

### 6.1 闭式手动前重点检查

1. 氮气来源正常，`SV_JD进氮压力` 和 `PV_JD进氮压力` 在允许范围内。
2. 爆破片反馈正常，安全泄压机构完好。
3. 氧含仪状态正常，氧含量测量可信。
4. 闭式隔断阀与开式隔断阀状态明确，避免两套风路同时导通。
5. 需特别关注：
   `QBS闭式排风隔断阀`、`QBS闭式进风隔断阀`、`QBD补氮阀`、`QJD进氮阀`、`QXY泄压阀`、氧含量隔断阀等。

### 6.2 建议操作步骤

1. 先确认开式阀门关闭、闭式阀门打开方向正确。
2. 手动试动补氮阀、进氮阀、泄压阀，验证开关反馈。
3. 手动建立闭式系统压力，观察 `PV_TN塔内压力` 与 `PV_JD进氮压力`。
4. 启动送风机、引风机和必要循环设备，确认闭式循环风路稳定。
5. 启动离心雾化器并观察油压、转速、风扇状态。
6. 条件稳定后再试动进料泵。
7. 手动验证布袋反吹、振打、出料动作。

### 6.3 运行中重点监视

1. `PV_TN塔内压力`
2. `PV_YH氧含仪1`、`PV_YH氧含仪2`
3. `PV_BD布袋压差变送器`
4. `PV_JF进风温度`、`PV_CF出风温度`
5. `PV_LX离心雾化油压`

### 6.4 闭式手动停机建议

1. 先停进料。
2. 维持循环风和必要惰化，避免系统内残留可燃气氛和积料。
3. 再停雾化与加热。
4. 压力稳定后，按工艺要求执行保压、泄压或补氮结束动作。

## 7. 闭式自动操作流程

主页面：`B2_闭式自动界面`

参数页面：`B3_闭式自动参数A`、`B4_闭式自动参数B`

### 7.1 闭式自动的程序特征

当前工程的 `C2-闭式自动_DB` 显示，闭式自动包含以下核心逻辑：

1. `闭式自动喷雾块`
2. `闭式保压块`
3. 多组 `步段延迟`
4. 多个运行时间累计器
5. 布袋记录块 `D3-布袋记录`
6. 自动停止、清理布袋、进风流量等边沿检测

这说明闭式自动不是简单的“一键启动”，而是带步段、保压、计时、布袋记录和多条件切换的完整顺控。

结合现场源码截图，还可以进一步确认 `C2-闭式自动` 外层 FB 至少做了以下事情：

1. 当 `PW.MS模式设定 = 1.0` 时，调用 `#闭式自动喷雾`。
2. 调用时把 `PV.TN塔内压力` 作为主塔压力输入。
3. 将自动运行报警、步段运行时分秒、总运行时分秒、进料时分秒统一回写到 `BS` 数据区。
4. 将 `BS.BD步段设定`、`BS.BD步段运行`、`BS.ZD自动停止`、`BS.AQ安全停机` 作为自动流程关键状态量参与顺控。
5. 截图中还出现了一个被注释的 `#四参数辅助`，其用途是对送风相关量做辅助调节，说明闭式自动外围还预留了送风优化逻辑。

这意味着 `C2-闭式自动` 本身是“闭式自动主顺控的外层包装块”，而真正的步骤推进核心在 `#闭式自动喷雾` 内部。

### 7.2 自动前参数确认

闭式自动建议至少确认以下参数：

1. 主塔压力设定和高低报警值。
2. 氧含量高报/高高报值。
3. 进风温度、出风温度设定与保护值。
4. 引风、送风、雾化、进料频率自动设定。
5. 布袋压差高报、高高报、自动反吹设定。
6. 进料流量、进料压力、停机阈值。
7. 保压相关时间、压差和阶段条件。

### 7.3 自动启动建议顺序

1. 进入 `B2_闭式自动界面`，确认无未复位故障。
2. 确认闭式阀门初始位正确，开式阀门未误开。
3. 确认氧含量、氮气压力、塔压均在允许启动范围。
4. 启动闭式自动后，系统通常应按以下思路推进：
   先做联锁自检与闭式通路确认，再建立塔内压力和保压条件，然后投入风机、温控、雾化和进料，运行中按布袋压差和步段逻辑执行反吹、振打和出料。
5. 若任一关键条件超限，如塔压、氧含量、爆破片、氮气压力、阀门反馈、风机/雾化器故障，系统应进入报警或保护停机。

从源码接口能确认的关键闭式自动状态量包括：

1. `BS.ZD自动运行报警`
2. `BS.BD步段运行_秒 / 分 / 时`
3. `BS.ZY总运行_秒 / 分 / 时`
4. `BS.JL进料_秒 / 分 / 时`
5. `BS.YP顶喷雾检测系统正常`
6. `BS.BD步段设定`
7. `BS.BD步段运行`
8. `BS.ZD自动停止`
9. `BS.AQ安全停机`

操作员如果要判断闭式自动卡在哪一步，优先就应查看这些 `BS` 量及其在 HMI 上的对应显示。

### 7.4 运行中操作员要点

1. 优先看 `B2_闭式自动界面` 的运行阶段、自动状态和停止原因。
2. 配合 `D3_数据与曲线`、`D6_喷雾压差曲线`、`D7_喷雾压力曲线`、`D8_喷雾温度曲线` 观察趋势。
3. 氧含量、塔压、布袋压差、雾化油压是闭式运行的关键判断量。
4. 如自动频繁停在某一阶段，应对照 `D2_连锁参数` 和当前阀反馈、压力、氧含量逐项排查。

### 7.5 自动停机建议

1. 优先使用“自动停止”，不要直接强制断电停主设备。
2. 让系统按顺控先切断进料，再退出喷雾与加热。
3. 维持闭式风路和必要保压/补氮动作，直到塔内状态恢复到允许结束条件。
4. 停机后复核报警历史和操作日志，确认是否存在保护停机原因。

## 8. 室内 CIP 手动操作流程

对应页面：`X4_室内清洗手动流程`

室内 CIP 手动主要用于检修、试水、单阀确认、排障和自动流程前验证。

### 8.1 手动前条件

1. 生产流程必须完全停止。
2. 加热、雾化、进料、输送和出料设备退出运行。
3. 系统已确认不会带压带料进入清洗。
4. 清洗介质来源明确：纯水、碱水、溶剂、二次纯水。
5. 排液回收路径畅通。

### 8.2 手动动作建议

1. 先开总阀，再开回水阀、进液阀、排液阀，确认流向。
2. 逐一动作塔顶清洗球阀、主塔清洗进水阀、旋风与除尘清洗阀、输送管路清洗阀、料仓清洗阀等。
3. 试动清洗伸缩气缸，确认升降反馈。
4. 若涉及溶剂回收和排液泵，先确认排液路径，再启动泵。
5. 单步验证完成后再退出手动。

### 8.3 与程序对应的重点对象

`B4-清洗连锁` 明确包含以下关键对象：

1. `QTD塔顶清洗球阀`
2. `QZT主塔清洗进水阀`
3. `QXF旋风管道清洗阀`
4. `QYJ一级旋风清洗阀`
5. `QEJ二级旋风清洗阀`
6. `QCC除尘管道清洗阀`
7. `QCC除尘清洗阀`
8. `IQX清洗伸缩气缸升反馈`
9. `IQX清洗伸缩气缸降反馈`

## 9. 室内 CIP 自动操作流程

主页面：`X5_室内清洗自动流程`

参数页面：`X6_室内清洗参数`

### 9.1 自动前确认

1. 室内 CIP 管路已接通，介质足够。
2. 排液与回收路径已确认。
3. 关键阀门和气缸反馈正常。
4. 清洗程序配方、时间、步骤、切换条件已检查。

根据源码截图，`C3-室内CIP清洗` 外层块会把以下关键命令和对象交给 `#室内CIP清洗` 核心块：

1. 自动清洗：`INCIP.MZD自动清洗`
2. 清洗重量：`INCIP.MQX清洗重量`
3. 手动纯水清洗：`INCIP.MSD手动_纯水清洗`
4. 手动碱水清洗：`INCIP.MSD手动_碱水清洗`
5. 手动溶剂清洗：`INCIP.MSD手动_溶剂清洗`
6. 手动热水清洗：`INCIP.MSD手动_热水清洗`

同时它还把室内清洗相关阀门请求和设备动作一并映射进去，包括：

1. 纯水、热水、碱水、溶剂、压干、泄压等“请求量”
2. 主塔清洗进水阀
3. 主塔清洗阀

10. 输送管路清洗阀
11. 料仓清洗阀

### 9.2 自动运行建议

1. 在 `X6_室内清洗参数` 设置各阶段时间与切换条件。
2. 进入 `X5_室内清洗自动流程`，确认当前模式是室内自动清洗。
3. 启动自动后，系统应按预设配方执行纯水、碱水、溶剂、二次纯水等阶段。
4. 自动中应重点确认：
   清洗介质是否到位、排液是否顺畅、清洗球阀和伸缩气缸反馈是否一致、无缺水/缺液报警。
5. 若过程停在某一步，优先检查：
   阀反馈、气缸反馈、液位、流量、缺水、泵状态、通讯状态。

结合接口命名，室内 CIP 自动的实际推进逻辑应至少覆盖以下阶段对象：

1. 清洗总通路建立
2. 介质来源选择
3. 主塔清洗
4. 旋风段清洗
5. 除尘段清洗
6. 输送段清洗
7. 料仓/料罐清洗
8. 出风高效清洗

因此在编写正式 SOP 时，建议把室内 CIP 再细分为“介质选择步骤”和“设备段落步骤”两层。

## 10. 室外 CIP 手动操作流程

对应页面：`X1_室外清洗手动流程`

操作原则与室内手动清洗相同，但重点对象为室外清洗单元、室外回水、室外管路及与室外设备相关的通讯联动。

建议步骤：

1. 停产并切换到室外清洗准备状态。
2. 手动确认室外总阀、回水阀、排液阀及室外相关泵阀。
3. 单步检查与室外清洗相关的阀门反馈和流向。
4. 确认无泄漏、无误动作后再转自动。

## 11. 室外 CIP 自动操作流程

主页面：`X2_室外清洗自动流程`

参数页面：`X3_室外清洗参数`

建议步骤：

1. 在 `X3` 设定室外清洗配方、时间与步骤。
2. 在 `X2` 启动自动清洗。
3. 观察室外清洗通讯、泵阀状态、回水与排液状态。
4. 自动结束后确认所有清洗阀复位、排液结束、系统回到安全待机位。

从你提供的源码截图可以进一步确认，`C4-室外CIP清洗` 外层块调用的是 `#室外CIP清洗`，并把以下量传入：

1. 自动清洗：`OUTCIP.MZD自动清洗`
2. 清洗重量：`OUTCIP.MQX清洗重量`
3. 手动纯水/碱水/溶剂/热水清洗命令
4. 中途停止：`OUTCIP.MZT中途停止`
5. 电导率合格值：`OUTCIP.DD电导率合格值`

室外 CIP 使用的重点设备对象则明显偏向外循环和换热端，包括：

1. 一级冷凝清洗阀
2. 二级冷凝清洗阀
3. 引风机清洗阀
4. 送风机清洗阀
5. 加热清洗阀
6. 蜗壳清洗阀

这说明室外 CIP 的重点不是塔内喷头，而是外部循环风路、冷凝与换热相关设备的自动冲洗。

因此室外 CIP 自动流程建议再明确拆成：

1. 清洗介质准备
2. 总通路建立
3. 冷凝段冲洗
4. 风机段冲洗
5. 加热段冲洗
6. 蜗壳段冲洗
7. 排液与结束复位

## 12. 注意事项

### 12.1 生产安全注意事项

1. 未建立稳定风量、温度和雾化条件前，禁止提前进料。
2. 布袋压差、塔压、氧含量异常时，不应强行维持闭式生产。
3. 爆破片反馈异常、氮气压力不足、补氮阀/进氮阀反馈异常时，禁止启动闭式自动。
4. 开式与闭式隔断阀不得同时处于误导通状态。
5. 手动模式仅用于确认动作，不宜长期生产运行。

### 12.2 清洗注意事项

1. CIP 前必须确认生产物料已退出系统。
2. 清洗和生产不得同时执行。
3. 涉及碱液、溶剂时，应重点确认介质切换和排放回收路径。
4. 清洗球阀和伸缩气缸动作必须有反馈确认后再进入下一步。

### 12.3 维护与调试注意事项

1. 任何 I/O 调整后，应重新核对 `0- IO Configure` 的映射。
2. 修改报警阈值前，应先备份工艺设定。
3. 发现历史数据或操作日志不更新时，应检查 HMI 存储卡路径和 VB 脚本运行条件。

## 13. 报警与故障说明

当前工程报警点很多，建议按类别理解和处理。

### 13.1 温度类报警

典型报警：

1. `AJF进风温度高报`
2. `AJF进风温度高高报`
3. `ACF出风温度高报`
4. `ACF出风温度高高报`
5. `AWQ尾气温度高报`
6. `AWQ尾气温度高高报`
7. `AWK温控高温报警`

处理原则：

1. 检查温控设定与实时值偏差。
2. 检查加热调节阀反馈、送风量、引风量、进料量是否失衡。
3. 必要时先减料，再退加热。

### 13.2 压力与压差类报警

典型报警：

1. `ABD布袋压差高报`
2. `ABD布袋压差高高报`
3. `AJF进风压差高报`
4. `AJF进风压差高高报`
5. `ATN塔内压力低报`
6. `ATN塔内压力低低报`
7. `ATN塔内压力高报`
8. `ATN塔内压力高高报`
9. `AJD进氮压力低报`

处理原则：

1. 优先确认风机状态、阀位、补氮状态、脉冲反吹动作。
2. 闭式模式下同时看塔压和氧含量，不可只盯单一压力值。

### 13.3 执行机构反馈类报警

典型报警：

1. `AQL气流雾化阀开报警`
2. `AQL气流雾化阀关报警`
3. `ATD塔顶清洗球阀开报警`
4. `ATD塔顶清洗球阀关报警`
5. `AQX清洗伸缩气缸开报警`
6. `AQX清洗伸缩气缸关报警`
7. 一级、二级、除尘、闭式隔断阀等各类开关到位报警

处理原则：

1. 检查气源、阀岛、线圈、限位开关和机械卡滞。
2. 先确认现场是否动作，再判断是执行问题还是反馈问题。

### 13.4 主设备故障类报警

典型报警：

1. `ASF送风机报警`
2. `AYF引风机报警`
3. `ALX离心雾化故障`
4. `ADJ电加热报警`
5. `ASF输送风机故障报警`
6. `ASF输送加热故障报警`

处理原则：

1. 先看变频器/接触器/热继电器/保护模块。
2. 再看 PLC 输出命令是否正常发出、反馈是否返回。

### 13.5 安全与公用工程类报警

典型报警：

1. `AKY空压低压信号`
2. `ABP爆破片1反馈报警`
3. `ABP爆破片2反馈报警`
4. `ACIP缺水报警`
5. `AWH雾化油压低报`
6. `AWH雾化油压低低报`

处理原则：

1. 安全类报警不应直接强制屏蔽后继续生产。
2. 必须先恢复公用工程和安全回路，再允许重新启动。

### 13.6 报警页面使用建议

1. `A3_故障报警`：看当前未复位报警。
2. `A4_历史报警`：查报警出现时间和恢复时间。
3. `D1_报警参数`：调整阈值前先记录原值。
4. `D5_操作日志`：核对人为操作动作。

## 14. 历史数据与日志说明
