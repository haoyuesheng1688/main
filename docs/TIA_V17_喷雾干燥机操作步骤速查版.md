# TIA V17 喷雾干燥机操作步骤速查版

适用对象：操作员、班长、调试人员  
适用工程：`A区北面2000`

说明：这份文件只写“怎么操作”，不展开讲程序架构。需要看报警分类、I/O 附录、VB 和程序结构时，再看完整版说明书。

## 1. 开式手动操作步骤

对应页面：

1. `C1_开式手动界面`
2. `D1_报警参数`
3. `A3_故障报警`

操作步骤：

1. 进入 `A3_故障报警`，确认无急停、无主设备故障、无关键阀门未到位报警。
2. 进入 `C1_开式手动界面`，确认当前不是闭式自动、不是 CIP 自动。
3. 确认开式隔断阀准备正确：
   `QKS开式排风隔断阀`、`QKS开式进风隔断阀` 应允许动作；
   `QBS闭式排风隔断阀`、`QBS闭式进风隔断阀` 不应误开。
4. 手动打开开式风路相关阀门，观察开关反馈正常。
5. 手动启动送风机，确认送风机运行反馈正常。
6. 手动启动引风机，确认引风机运行反馈正常。
7. 若工艺需要，再手动启动电加热、输送风机、输送加热。
8. 手动启动离心雾化器，观察雾化器、风扇、油泵状态。
9. 温度、风量、塔压稳定后，再手动启动进料泵。
10. 需要时再投入布袋反吹、振打、出料阀等辅助动作。
11. 运行中持续观察：
    `PV_JF进风温度`、`PV_CF出风温度`、`PV_TN塔内压力`、`PV_JL进料压力`、`PV_BD布袋压差变送器`。

手动停机步骤：

1. 先停进料泵。
2. 再退雾化。
3. 再退加热。
4. 保留送风、引风短时运行，把塔内余热和残料带走。
5. 最后停送风机、引风机。
6. 关闭开式通路阀门，恢复待机状态。

## 2. 开式自动操作步骤

对应页面：

1. `C2_开式自动界面`
2. `C3_开式自动参数A`
3. `C4_开式自动参数B`
4. `D3_数据与曲线`
5. `A3_故障报警`

自动启动前步骤：

1. 进入 `C3`、`C4`，先确认自动参数。
2. 重点确认以下设定值：
   `SV_JF进风温度设定`
   `SV_CF出风温度设定`
   `SV_YF引风频率设定`
   `SV_JL进料泵频率设定`
   `SV_BD布袋压差自动反吹`
   `SV_BD布袋反吹时间`
   `SV_BD布袋振打时间`
3. 回到 `C2_开式自动界面`，确认无报警、无联锁阻止。
4. 确认开式风路打开、闭式风路关闭。
5. 确认冷却水、冷冻水、进风冷却水、空压正常。

自动启动操作：

1. 在 `C2_开式自动界面` 选择开式自动模式。
2. 按“自动启动”。
3. 观察程序是否依次建立以下条件：
   风路建立
   温度建立
   雾化投入
   进料投入
   布袋反吹/振打/出料进入自动节拍
4. 自动运行中重点看：
   进风温度
   出风温度
   塔内压力
   布袋压差
   进料压力
   送风/引风/雾化/进料频率
5. 若出风温度偏高、塔压异常、布袋压差异常，先减料，再判断是否需要停自动。

自动停机操作：

1. 在 `C2_开式自动界面` 按“自动停止”。
2. 系统正常逻辑应先退进料，再退喷雾和加热。
3. 送风、引风会短时保留运行。
4. 等塔内温度和压力回落后，再完全停机。
5. 停机后查看 `A3_故障报警` 和 `D3_数据与曲线`，确认是否为正常停机。

## 3. 闭式手动操作步骤

对应页面：

1. `B1_闭式手动界面`
2. `A3_故障报警`
3. `D3_数据与曲线`

操作步骤：

1. 确认当前不是开式自动，不是 CIP 自动。
2. 确认氮气具备条件，`PV_JD进氮压力` 正常。
3. 确认氧含量仪正常，爆破片反馈正常。
4. 手动检查闭式关键阀门：
   `QBS闭式排风隔断阀`
   `QBS闭式进风隔断阀`
   `QBD补氮阀`
   `QJD进氮阀`
   `QXY泄压阀`
5. 手动建立闭式通路，确认开式隔断阀关闭。
6. 手动补氮或进氮，观察塔内压力变化。
7. 启动送风机和引风机，建立闭式循环。
8. 启动离心雾化器，确认油压、风扇、主机状态正常。
9. 条件稳定后再启动进料泵。
10. 运行中重点观察：
    `PV_TN塔内压力`
    `PV_YH氧含仪1`
    `PV_YH氧含仪2`
    `PV_BD布袋压差变送器`
    `PV_LX离心雾化油压`

手动停机步骤：

1. 先停进料。
2. 再退喷雾和加热。
3. 保留循环风和必要保压动作。
4. 压力稳定后再退风机和补氮动作。
5. 最后恢复闭式待机阀位。

## 4. 闭式自动操作步骤

对应页面：

1. `B2_闭式自动界面`
2. `B3_闭式自动参数A`
3. `B4_闭式自动参数B`
4. `D6_喷雾压差曲线`
5. `D7_喷雾压力曲线`
6. `D8_喷雾温度曲线`

自动启动前步骤：

1. 进入 `B3`、`B4`，先确认闭式自动参数。
2. 重点确认：
   塔压设定
   氧含量报警值
   进风温度设定
   出风温度设定
   引风/送风/雾化/进料频率自动设定
   布袋压差自动反吹相关设定
3. 回到 `B2_闭式自动界面`。
4. 确认闭式隔断阀通路正确，开式隔断阀关闭。
5. 确认氮气、氧含量、爆破片、塔压都满足启动条件。

自动启动操作：

1. 在 `B2_闭式自动界面` 选择闭式自动模式。
2. 按“自动启动”。
3. 观察系统是否依次完成：
   闭式通路确认
   保压/补氮建立
   风路建立
   温度建立
   雾化投入
   进料投入
   布袋反吹和出料节拍投入
4. 自动运行中重点关注 `BS` 相关状态显示：
   步段设定
   步段运行
   自动运行报警
   自动停止
   安全停机
   步段运行时间
   总运行时间
   进料运行时间
5. 配合趋势页观察：
   塔压
   温度
   布袋压差
   氧含量
   雾化油压

自动停机操作：

1. 在 `B2_闭式自动界面` 按“自动停止”。
2. 系统应先停进料，再退喷雾和加热。
3. 保持闭式循环和必要保压，直到塔内状态恢复正常。
4. 若出现 `安全停机`，先查原因，禁止直接强行重启。

## 5. 室内 CIP 手动操作步骤

对应页面：

1. `X4_室内清洗手动流程`
2. `X6_室内清洗参数`

操作步骤：

1. 确认生产已停机，系统不带料、不带压。
2. 进入 `X4_室内清洗手动流程`。
3. 确认清洗介质已具备：
   纯水、碱水、溶剂、热水。
4. 先手动建立室内清洗总通路。
5. 按需要选择单步动作：
   纯水清洗
   碱水清洗
   溶剂清洗
   热水清洗
6. 逐个验证以下对象是否动作正确：
   主塔清洗进水阀
   主塔清洗阀
   旋风管道清洗阀
   一级旋风清洗阀
   二级旋风清洗阀
   除尘管道清洗阀
   除尘清洗阀
   输送管路清洗阀
   料仓清洗阀
   料罐清洗阀
   出风高效清洗阀
7. 手动试动清洗伸缩气缸，确认升降反馈。
8. 确认排液路径畅通后，再进行较长时间清洗。
9. 手动结束后，把各阀门恢复到待机位。

## 6. 室内 CIP 自动操作步骤

对应页面：

1. `X5_室内清洗自动流程`
2. `X6_室内清洗参数`

自动前设置：

1. 在 `X6_室内清洗参数` 设置清洗配方和步骤时间。
2. 重点确认：
   自动清洗使能
   清洗重量
   电导率合格值
   是否允许中途停止

自动启动操作：

1. 进入 `X5_室内清洗自动流程`。
2. 选择室内 CIP 自动。
3. 按“自动启动”。
4. 观察系统是否依次完成：
   建立清洗总通路
   选择清洗介质
   主塔清洗
   旋风段清洗
   除尘段清洗
   输送段清洗
   料仓/料罐清洗
   出风高效清洗
5. 运行中重点检查：
   阀门反馈
   气缸反馈
   排液状态
   缺水或缺液报警
   电导率是否达标

自动停止操作：

1. 正常结束时等待程序自动复位。
2. 中途需要停止时，按“中途停止”。
3. 停止后确认所有清洗阀复位，排液完成，系统回到安全待机状态。

## 7. 室外 CIP 手动操作步骤

对应页面：

1. `X1_室外清洗手动流程`
2. `X3_室外清洗参数`

操作步骤：

1. 确认生产完全停止。
2. 进入 `X1_室外清洗手动流程`。
3. 确认室外清洗介质和回收路径具备条件。
4. 手动建立室外清洗通路。
5. 逐步验证以下对象：
   一级冷凝清洗阀
   二级冷凝清洗阀
   引风机清洗阀
   送风机清洗阀
   加热清洗阀
   蜗壳清洗阀
6. 检查排液、回流和现场泄漏情况。
7. 手动结束后恢复待机位。

## 8. 室外 CIP 自动操作步骤

对应页面：

1. `X2_室外清洗自动流程`
2. `X3_室外清洗参数`

自动前设置：

1. 在 `X3_室外清洗参数` 设置室外清洗参数。
2. 确认：
   自动清洗使能
   清洗重量
   电导率合格值
   中途停止条件

自动启动操作：

1. 进入 `X2_室外清洗自动流程`。
2. 选择室外 CIP 自动。
3. 按“自动启动”。
4. 观察系统是否依次完成：
   介质准备
   总通路建立
   一级冷凝冲洗
   二级冷凝冲洗
   引风机冲洗
   送风机冲洗
   加热段冲洗
   蜗壳冲洗

   清洗液是否到位

   缺水报警

自动停止操作：

2. 需要中断时按“中途停止”。
3. 停止后确认外部清洗阀全部复位。

## 9. 自动运行时操作员只盯这几项

开式自动重点看：

1. 进风温度
2. 出风温度
3. 塔内压力
4. 布袋压差
5. 进料压力

闭式自动重点看：

1. 塔内压力
2. 氧含量
3. 布袋压差
4. 雾化油压
5. 自动步段和安全停机状态

CIP 自动重点看：

1. 当前步骤
2. 阀门反馈
3. 排液状态
4. 电导率或清洗合格条件
5. 缺水、缺液、通讯异常

## 10. 一旦自动不走，先查这 5 类

1. 当前模式选错了。
2. 有未复位报警或联锁。
3. 阀门开关反馈不到位。
4. 公用工程不到位：
   冷却水、冷冻水、空压、氮气、纯水、碱液、溶剂。
5. 关键工艺量超限：
   温度、塔压、布袋压差、氧含量、油压。
