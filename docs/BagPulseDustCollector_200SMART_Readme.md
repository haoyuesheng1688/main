# S7-200 SMART 脉冲布袋除尘器程序说明

本目录里的 `BagPulseDustCollector_200SMART_OB1.awl` 是给 STEP 7-Micro/WIN SMART 的 STL/语句表 ASCII 导入文件，已在当前 V2.8 软件中导入并编译通过。文件按 LAD 友好格式拆成多个小 `NETWORK`，尽量保证一个程序段只包含一个梯级/动作，避免 LAD 视图出现“无效程序段”。它做了一个输入到输出的闭环：物理输入 `I0.x` 先映射到 `V0.x` 控制位，状态机按参数运行，再输出到 `Q0.x`。

## 在 200SMART 软件里导入

1. 打开 STEP 7-Micro/WIN SMART 当前工程。
2. 菜单 `File` -> `Import` 下拉 -> 选择 `POU`。
3. 选择本文件夹的 `BagPulseDustCollector_200SMART_OB1.awl`。
4. 导入后切换到 `STL` 编辑器检查错误；如果软件生成同名 `.err`，按错误行修正后重新导入。

注意：导入 OB1 会替换/删除当前已有 POU。若当前工程里已有重要程序，先另存工程，或把 AWL 内容改成子程序再导入。

## I/O 地址

| 地址 | 含义 |
| --- | --- |
| `I0.0` | 启用 Enable |
| `I0.1` | 复位 Reset |
| `I0.2` | 运行许可 RunPermit |
| `I0.3` | 清灰请求 CleanRequest |
| `I0.4` | 压差高 DpHigh |
| `I0.5` | 压差低 DpLow |
| `I0.6` | 连续循环 ContinuousMode |
| `I0.7` | 手动脉冲 ManualPulse，上升沿触发 |
| `Q0.0` | 1 号布袋脉冲阀 |
| `Q0.1` | 2 号布袋脉冲阀 |
| `Q0.2` | 3 号布袋脉冲阀 |
| `Q0.3` | 4 号布袋脉冲阀 |
| `Q0.4` | Running |
| `Q0.5` | Alarm |
| `Q0.6` | AutoRequestLatched |
| `Q0.7` | RunPermit 回显 |

## 可调参数

| 地址 | 默认值 | 单位 | 含义 |
| --- | --- | --- | --- |
| `VB100` | `4` | 个 | 布袋数量，程序限制为 `1..4` |
| `VW102` | `20` | 10 ms | 通用脉冲时间，20 = 200 ms |
| `VW104` | `500` | 10 ms | 阀间隔时间，500 = 5 s |
| `VW106` | `18000` | 100 ms | 连续循环暂停，18000 = 30 min |
| `VB108` | `1` | 号 | 手动脉冲布袋号 |
| `V3.0` | `1` | Bool | 是否启用单袋脉冲时间 |
| `VW120` | `0` | 10 ms | 1 号单独脉冲时间，0 表示用 `VW102` |
| `VW122` | `0` | 10 ms | 2 号单独脉冲时间，0 表示用 `VW102` |
| `VW124` | `0` | 10 ms | 3 号单独脉冲时间，0 表示用 `VW102` |
| `VW126` | `0` | 10 ms | 4 号单独脉冲时间，0 表示用 `VW102` |

## 状态寄存器

| 地址 | 含义 |
| --- | --- |
| `VB110` | 步号：0 空闲，10 脉冲，20 阀间隔，30 周期暂停，40 手动脉冲 |
| `VB111` | 当前布袋号 |
| `V1.0` | 自动清灰请求锁存 |
| `V1.1` | 一个周期完成的内部单扫标志 |
| `V1.2` | 参数/手动选择报警 |
| `V1.4` | 手动脉冲上升沿 |
| `VW128` | 当前实际脉冲时间 |

## 运行逻辑

启用后，`CleanRequest`、`DpHigh` 或 `ContinuousMode` 会锁存自动清灰请求。满足 `RunPermit` 后从 1 号布袋开始，按 `VB100` 的布袋数量依次打开 `Q0.0..Q0.3`，每个阀打开 `VW128` 时间，中间等待 `VW104`。一个周期完成后，如果连续模式有效，或压差高且未达到压差低，则进入 `VW106` 周期暂停后重新开始；否则回到空闲。

手动模式在 `I0.7` 上升沿触发，按 `VB108` 指定布袋号脉冲一次。`VB108` 超范围时置位 `V1.2/Q0.5` 报警。
